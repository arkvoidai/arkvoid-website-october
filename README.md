# Arkvoid — A world that remembers

A responsive static website explaining Arkvoid in plain language: a digital world where characters can remember events, choices have consequences, and the world keeps a reliable history.

## Files
- `index.html` — page structure and plain-language product story
- `styles.css` — responsive layouts, forest/ivory/sage/copper design system, animation and reduced-motion support
- `script.js` — accessible mobile navigation, scroll reveals and the interactive three-step story
- `assets/arkvoid-symbol.svg` — custom mark and favicon
- `assets/persistent-world.svg` — lightweight animated vector concept artwork

## Run locally
Open `index.html` in a modern browser. There is no build step and no runtime dependency.

## Deploy to Vercel
Import this repository into Vercel as a static site. No framework preset or build command is required; the site can be served from the repository root. Keep the `assets/` folder alongside the HTML file so the relative image paths resolve.

## Design and accessibility
- Mobile-first responsive layout with a compact menu on small screens
- Original local vector artwork; no external font or animation-library downloads
- Scroll reveals and ambient movement with `prefers-reduced-motion` support
- Semantic sections, keyboard focus states and skip link
- Interactive story works without a backend

## Research integrity
The proposed metrics are clearly labelled as research targets, not achieved results. The example story is illustrative, not a live feature. The roadmap is conditional and does not imply that future platform or hardware plans are already built.
