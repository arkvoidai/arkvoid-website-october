01 / THE VISIONFROM SESSIONS TO ENVIRONMENTS

A DIFFERENT UNIT OF COMPUTING

Not another app to open.
A place that carries its past.

Today's digital experiences often stop at the edge of a session. Arkvoid is exploring software that behaves more like an environment.

Its inhabitants have stable identities, changing relationships, active goals and memories tied to events. The world owns the record of what actually happened. On your next visit, people and places can respond to that history.

This is a proposed research direction, not an established industry category or a claim that the problem is solved.

The living world.
Worth coming back to.

The first product is a browser-accessible cultivation world. Not because Arkvoid is only a game company, but because a living world makes continuity visible.

Enter a sect courtyard. Speak with five to ten named inhabitants. Ask for guidance, train, inspect an object or investigate a clue. Change a relationship or uncover a secret. Leave, return, and test whether the world can explain what changed.

04 / THE ENGINENOT A MONOLITHIC MODEL

AI proposes.
The world decides.

The central rule is simple: a model can propose dialogue or an action, but it cannot directly change canonical world state, ownership or inventory.

01 / RECORD

Event journal

An append-only record of actions and outcomes. State can be checked against its history.

02 / RECALL

Grounded memory

Separate episodic facts, relationship summaries, stable traits, current goals and uncertain beliefs. Keep the source event for each fact.

03 / VALIDATE

World authority

Typed commands, preconditions, permissions, idempotency and deterministic state changes. Models never silently rewrite canon.

04 / CONTINUE

Agent lifecycle

Observe, recall, decide, propose, validate, commit, then sleep and resume with schedules and safe recovery.

ARKVOID should not claim that AI memory, world generation or agent compilation are new by themselves. The question is whether the pieces can work together with stronger correctness and lower cost.

06 / THE LANDSCAPECOMPLEMENTARY BEFORE COMPETITIVE

Different systems solve
different parts of the problem.

Arkvoid is not building a new foundation model or another 3D engine. The opportunity, if evidence supports it, is a world runtime that connects generation, agents and authoritative state.

WORLD GENERATION

Genie 3 ↗ · Marble ↗

Create and explore generated worlds. Generation alone does not settle long-lived identity, multi-agent relationships, ownership or event recovery.

AGENT CONTROL

SIMA 2 ↗

AI agents can understand instructions and act in virtual environments. Arkvoid still needs to prove reliable persistent state around actions and memories.

RENDERING & SIMULATION

Unreal · Unity · NVIDIA

Mature engines and infrastructure should be used where they help. Arkvoid’s hypothesised layer is world-state semantics, character lifecycle, evaluation and cost control.

ARKVOID / THE OPEN QUESTION

A world engine

Can authoritative events, grounded memory and sparse simulation create a world that is more coherent and cheaper to operate than a well-engineered integration of existing tools?

07 / EXECUTIONGATES, NOT PROMISES

Start with a world.
Earn the platform.

The world is the first emotional test. The engine is the reusable technical asset. A broader computing platform is a later option, unlocked by evidence.

01 / NOW

The living world

One sect courtyard, five to ten inhabitants, meaningful actions, grounded memory and persistent state.

PROOF: STATE SURVIVES LEAVING AND RETURNING
02 / NEXT

The world engine

A reusable runtime for event history, character lifecycle, deterministic transitions, simulation tiers and evaluation.

PROOF: REPEATABLE CORRECTNESS AND COST ADVANTAGE
03 / LATER

The computing platform

Versioned interfaces and APIs across browser, phone and XR. Hardware only if existing devices leave a proven user need.

THE STOP RULE

If the experience is only novel, narrow the thesis. If user value and technical advantage improve together, earn the next phase.

08 / WHO IT STARTS WITHDESIRE BEFORE SCALE

Find the people
who want to return.

The first audience is concentrated, not universal: cultivation-fiction and persistent-roleplay enthusiasts who care whether a character remembers a meaningful choice.

01

10–20 design partners

Observe people using the same memory-dependent interactions more than once.

02

A closed test

Measure first-session activation, seven-day return, meaningful actions, contradictions and resets.

03

A paid signal

Only after users experience durable consequences, test premium access and willingness to pay.

04

Then developers

Ask outside creators to build on the engine once it solves a problem they cannot easily solve alone.
