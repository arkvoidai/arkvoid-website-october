01 / THE THESISFROM SESSION TO ENVIRONMENT

NOT ANOTHER LAYER OF CHAT

Software that behaves less like a session. More like a place.

Most digital experiences begin when you arrive and stop when you leave. Arkvoid is investigating a different model: environments with durable history, inhabitants with bounded continuity, and consequences that survive the session.

Generated scenes, AI agents, simulation and persistent workflows already exist in different forms. The open engineering challenge is to make them work together as one observable, affordable and device-independent runtime. That is the hypothesis—not a claim that the problem is solved.

03 / RESEARCH AGENDAHYPOTHESES TO TEST · NOT RESULTS

Make the difficult parts measurable.

Arkvoid’s advantage, if one emerges, must be visible in repeatable benchmarks—not just in a beautiful scene or a strong demo.

R / 01◎

Persistent agent runtime

Keep identity, memory, relationships and goals coherent through time, restarts and interruptions.

EXIT TARGET≥95%state-fact correctness on a fixed test set
R / 02↻

Crystallizing execution

Test whether verified, recurring world routines can run faster while falling back safely when the state changes.

EXIT TARGET−40% / −50%p95 latency / model calls on eligible repeats

Prior-art aware: broad agent JIT compilation is already being researched. Any differentiation must be specific and measured.

R / 03≋

Sparse world simulation

Use deterministic schedules for quiet activity and reserve deeper model reasoning for moments that matter.

EXIT TARGET−70%background simulation cost without material continuity loss
R / 04⌘

Device-independent runtime

Keep world IDs, events, goals and permissions stable while input and rendering adapt to browser, phone or XR.
