01 / THE IDEA PLAIN AND SIMPLE

More like a place.
Less like a session.

Most apps forget the moment you close them. Arkvoid is exploring a digital world that keeps its history.

The characters, their plans, their friendships and the events around them should stay connected over time. When you leave and come back, the world should have something real to remember.

A / 01

A story can be made up.
A world should remember what actually happened.

01

People remember

A character should recall meeting you, not act like you are a stranger every time.

02

Choices leave a mark

If you help someone or change a place, later events should reflect that choice.

03

Time moves forward

Plans and relationships should continue within clear rules, even while you are away.

02 / HOW IT COULD WORK THE WORLD KEEPS THE RECORD

AI suggests.
Rules check.
The world remembers.

AI can suggest what a character might say or do. But a suggestion should not automatically become a fact.

The world checks the action, saves what really happened, and lets characters react to that record. That is how Arkvoid hopes to keep its world consistent.

01

You do something

A player or character takes an action.

02

AI suggests what happens next

The model proposes an action, dialogue or response.

03

The rules check it

The system checks what is allowed before changing the world.

04

The event is saved

The world keeps a record it can refer to later.

05

Characters react

Future choices can reflect what really happened.

This is a proposed design, not a claim that the full system is already built.

05 / WHAT MUST BE PROVED RESEARCH TARGETS, NOT RESULTS

Make the difficult parts measurable.

A beautiful world is not enough. The memory must hold up, the characters must stay consistent, and the system must be affordable to run.

R / 01

Can the world remember correctly?

Check a fixed set of events after many interactions and restarts.

95%+
Proposed target: correct facts on a defined test set
R / 02

Can repeated actions become faster?

Test whether verified routines can run again without asking a large model to solve them from scratch.

40–50%
Proposed reduction in latency or model calls on eligible repeats
R / 03

Can quiet moments cost less?

Use simple schedules for background activity and reserve deeper reasoning for moments that matter.

70%
Proposed reduction in background simulation cost, if quality holds

These are research goals from the October 2026 strategy plan, not achieved results. Benchmarks, baselines and test conditions must be published before any result can be claimed.

06 / THE ROADMAP GATES, NOT PROMISES

One validated step
at a time.

Each phase unlocks only after the previous claim survives testing.

PHASE 00

Define one location, character rules, the event format and a test suite.

GATE · One executable milestone
PHASE 01

Persist

Build the browser world, memory, routines, event log and restart recovery.

GATE · State survives restart
PHASE 02

Measure

Compare memory approaches and benchmark recurring routines and cost.

GATE · Repeatable benchmark win
PHASE 03

Validate

Run a small cohort, observe return visits, test safety and model costs.

GATE · Evidence of durable demand
PHASE 04

Offer the engine

Build APIs and developer tools only if outside users can benefit.
